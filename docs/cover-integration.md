# Интеграция каталога обложек

## Что проверено

`docs/games_covers_catalog.md` содержит 146 записей и ссылки на `arcade-haven-io.lovable.app`. На момент интеграции эти публичные URL возвращают `404`, поэтому сайт не должен зависеть от них напрямую.

В репозитории уже находятся `gamehaven-covers 1.zip` и `gamehaven-covers 2.zip`. Из них извлечены 79 JPG-файлов в `client/public/covers/catalog/`. Эти файлы обслуживаются самим сайтом через пути `/covers/catalog/<filename>`.

## Подключённые совпадения

В `shared/games.ts` локальные пути подключены для 32 игр: 12 с точным совпадением английского названия и 20 с однозначным переводом/смысловым совпадением названия:

- Block Bloom
- Circuit Sprint
- Goal Rush
- Hover Arena
- Neon Drift
- Pixel Frontier
- Portal Paws
- Prism Shift
- Skyline Raider
- Strike Point
- Turbo League
- Zero Zone

Дополнительно подключены переведённые пары вроде `Neon Riptide → Неоновый Прибой`, `Tideglass Cartographer → Картограф приливного стекла`, `Dune Phantom → Дюнный След` и `Moonpetal Farm → Фермер лунных семян`.

## Почему не подключены остальные записи

Остальные названия из 146-строчного каталога отсутствуют среди текущих игр или не совпадают однозначно. Их нельзя автоматически назначать похожим по смыслу играм: это может поставить неправильную обложку.

Следующий безопасный этап — составить отдельную таблицу подтверждённых соответствий для оставшихся названий и только после проверки добавить их в `shared/games.ts`.

## Автоматическое распределение

По запросу владельца оставшиеся 46 JPG из архивов распределены автоматически по свободным карточкам с учётом категории и близости тематики. Это эвристическое сопоставление, а не подтверждённая идентичность названий. Файл `Flower outline .png` оставлен как дубликат обложки Floral Contour и не назначался второй игре. Всего локально подключено 78 уникальных игровых изображений.
